# Publishing Guidance

`country-guides` is designed to work well in static websites, documentation portals, GitHub repositories, knowledge bases, and editorial systems.

## Recommended publishing model

Use the Markdown files as canonical source files. If the guides are republished to a website, avoid editing the website copy directly. Update the Markdown source first, then regenerate or copy the published version.

## Front matter compatibility

The guide front matter is intentionally simple. It should work with many static site systems, including Jekyll, Hugo, Eleventy, Astro, and custom Markdown pipelines.

## Suggested URL structure

For countries:

```text
/country-guides/canada/
/country-guides/france/
/country-guides/japan/
```

For cities:

```text
/city-guides/toronto-canada/
/city-guides/paris-france/
/city-guides/tokyo-japan/
```

## Reuse in larger systems

These guides can support:

- Travel planning websites
- Solo travel resources
- Digital nomad research hubs
- Open data portals
- Newsletter research libraries
- Country profile systems
- Lightweight public knowledge bases

## Editorial note for republishing

If guides are republished on a public website, include a visible last reviewed date and a reminder that travelers should verify critical details through official sources.
